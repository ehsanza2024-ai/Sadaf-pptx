# Sadaf-pptx — سامانهٔ تولید ارائهٔ علمی فارسی

این مخزن چارچوبی برای تولید ارائه‌های دانشگاهی فارسی با **محتوای مستند، ارزیابی شواهد، صفحه‌آرایی حرفه‌ای و کنترل کیفیت چندمرحله‌ای** است.

## پروژهٔ نمونه
**بررسی اثر کلستروم، کولین، کرومیوم، کاکائو و کوآنزیم Q10 بر عملکرد مغز و ذهن انسان**  
دانشگاه آزاد اسلامی واحد بابل — فیزیولوژی تغذیه  
استاد: آقای مسلم شریفی | ارائه‌دهنده: صدف سلمانزاده

## ساختار
- `.github/agents/academic-nutrition-presentation.agent.md`: پروفایل ایجنت پژوهش و تولید ارائه.
- `AGENTS.md`: قواعد عمومی پروژه برای ایجنت‌های کدنویسی/تولید محتوا.
- `prompts/master-presentation-fa.md`: دستور مادر برای طراحی و نگارش ارائه.
- `research/evidence-map.md`: نقشهٔ شواهد و منابعی که باید پیش از تولید نهایی بازبینی شوند.
- `quality/qa-checklist-fa.md`: چهار گذر کنترل علمی، ارجاع، نگارش فارسی و کیفیت بصری.

## اصل بنیادین
وجود یک سازوکار زیستی محتمل، به‌تنهایی اثبات نمی‌کند که مصرف خوراکی یک ماده، عملکرد شناختی انسان را بهبود می‌دهد. ایجنت باید شواهد انسانی را از مطالعات حیوانی/آزمایشگاهی جدا کند، نتایج منفی و محدودیت‌ها را گزارش دهد و از توصیهٔ مکمل یا ادعاهای درمانی بدون پشتوانه پرهیز کند.

## گردش کار پیشنهادی
1. منابع اولیه و مرورهای نظام‌مند را جست‌وجو و مشخصات کتاب‌شناختی آن‌ها را راستی‌آزمایی کن.
2. نقشهٔ ادعا ← منبع ← جمعیت ← مداخله ← پیامد ← محدودیت بساز.
3. روایت ارائه و متن هر اسلاید را بنویس؛ برای هر اسلاید ارجاع درون‌اسلایدی در نظر بگیر.
4. نسخهٔ قابل‌ویرایش PPTX، متن اسلایدها و راهنمای بسط شفاهی را تولید کن.
5. چهار گذر کنترل کیفیت را اجرا کن و موارد حل‌نشده را صریح علامت بزن.

## وضعیت
این شاخه برای بازبینی آماده است؛ پروفایل ایجنت در مخزن تعریف شده، اما فعال‌سازی عملی آن در محیطی که از پروفایل‌های `.agent.md` پشتیبانی می‌کند باید از طریق همان محیط انجام شود.
